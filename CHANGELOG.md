# Changelog

## v1.0.0 — первый публичный релиз

Дата: 2026-05-09

### Добавлено

- Премиальный лендинг мебельного магазина «РУСЬ».
- Каталог мебели с поиском, категориями и ценовыми фильтрами.
- Карточки товаров с изображениями, ценой, размером и описанием.
- Заявка-корзина для связи с менеджером.
- Кабинет продавца для добавления товаров в браузере.
- Блоки о компании, услугах, карте, контактах и footer.
- SEO meta, Open Graph и Schema.org `FurnitureStore`.
- GitHub Pages workflow для публичного хостинга.
- Static checks workflow для базовой проверки проекта.

### Ограничения MVP

- Кабинет продавца работает на `localStorage`.
- Для общего каталога, доступного всем посетителям, нужен backend или CMS.
